The idea behind this project is to help me keep better track of groceries I buy. I would simply take a picture of the receipt, the line items on the receipt would be matched to one member of a set of items (e.g. ORG BANANAS -> bananas), and stored into a database. I would then be able to check if I already have something the next time I go grocery shopping.

Associated ideas include:
* Alerts when something is getting old
* Recipe suggestions
* Tracking ingredient consumption with photos of ingredients / cooked food
* Training specialized models for the various classification / text reading / image recognition tasks
* [Your idea here.]

Samsung smart fridges have many of these features, but not many people have Samsung smart fridges.

The other purpose of this is for me to learn new things.
